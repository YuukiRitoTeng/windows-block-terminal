# Wave Architecture Atlas

External static source index for Wave Terminal commit `a4447c1563b2df285ab89e76c82f91e1a1a49c1e`.

The Atlas is a navigational aid: file manifest, important symbols, dependency/event/RPC edges, runtime paths, product feature classification, and Windows Block Terminal relevance. It does not make deletion decisions and does not replace source review.

## Query surfaces

- `data/files.jsonl`, `symbols.jsonl`, `dependencies.jsonl`, `events.jsonl`, `rpc.jsonl`, `modules.jsonl`
- `architecture/` runtime and subsystem narratives
- `product/` feature and keep/hide/remove candidate analysis
- `COVERAGE.md` completeness metrics

Wave source remains read-only; all Atlas files live in the formal project repository.
