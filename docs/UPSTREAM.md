## Source Strategy

Windows Block Terminal maintains a full Wave downstream source baseline.

Wave provides the existing terminal runtime infrastructure, including PTY, shell session lifecycle, RPC/event infrastructure, terminal stream handling, and xterm.js terminal compatibility.

Windows Block Terminal product semantics are developed outside Wave's existing Block model through isolated runtime boundaries and the Command Journal domain.
